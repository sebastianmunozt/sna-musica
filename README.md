## Para la clase práctica

1. Descarga las dos bases Excel de la clase 2.
2. Abre el enlace de Google Colab cuando esté disponible. También puedes descargar el [cuaderno de respaldo](cuadernos/clase_mu_ch_principiantes.ipynb?raw=true) y abrirlo desde **Archivo → Subir cuaderno** en [Google Colab](https://colab.research.google.com/).
3. Comprueba que el entorno sea **R**, sube los dos Excel al panel **Archivos** y ejecuta las celdas en orden.

La base **mu-ch** contiene redes de colaboración dicotomizadas para dos periodos: cada vínculo indica al menos una canción compartida. Se utiliza en los ejercicios. La red egocéntrica en torno a Pablo Chill-e es **ficticia** y se utiliza sólo como ejemplo de visualización.
